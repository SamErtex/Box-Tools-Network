BOX TOOLS NETWORK — RELEASE NOTES 7.0.0

OPA / NOVA INTERFACE IXC

- Mantida a versão 7.0.0 no manifest.json.
- page-bridge.js roda no MAIN world em document_start e captura eventos Socket.IO da interface.
- A fila é lida por customer-services-ui:customer-service-queues:department:list.
- A assunção automática usa customer-services-ui:customer-service-actions:department:take-over,
  enviando customerServicesData: [{ id, channel }].
- A confirmação é correlacionada pelo evento customer-service:take-over e validada pelo ID
  do atendimento, status EA e atendente associado; a lista in-progress continua como confirmação
  complementar e como detecção de assunções manuais.
- A marcação de aguardando cliente usa POST /services/customer-services-ui/
  customer-service-actions/state/set-awaiting-for-customer com JSON:
  { customerServicesIds: [id], isAwaitingForCustomer: true }.
- Sucesso da marcação exige response.ok, type === "success" e data.success === true.
- Em falha, são feitas até três novas tentativas após 750 ms, 1.500 ms e 3.000 ms.
- Sucesso/falha da marcação gera toast no OPA. A marcação não gera notificação nativa vermelha.
- Mantidos os demais módulos, permissões, telas, popup, Dev Tools, validador de IP,
  redirecionamento de links de chaves e alarmes/notificações de pós-assunção.

MELHORIA OPA — TEMPO NA FILA ATUAL
- O tempo exibido nos cartões da fila passa a representar o tempo desde a última transferência de departamento.
- Quando não existe transferência de departamento, utiliza a data de abertura do atendimento.
- A interface é atualizada em tempo real, sem recarregar a página.
- A atualização é conservadora: só altera os rótulos quando a quantidade de temporizadores visíveis corresponde à quantidade de registros recebidos do Socket.IO.
